are already taken and it is 10:30 in Margaret's kitchen whatever the real time is. Burn captions in post.

## Fallbacks while recording

- If speech recognition misfires, type the same line; the transcript looks identical.
- If Bedrock is unavailable, the rule-based brain answers the same five beats (the brain badge says "rule brain" —
  mention it honestly in the voice-over).
- Reset between takes from the Demo menu; it clears the transcript and re-seeds.
